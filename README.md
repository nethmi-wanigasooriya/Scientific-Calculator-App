# Scientific Calculator App (Flutter)

A modern, responsive, and feature-rich Scientific Calculator application built with Flutter. It supports complex mathematical operations, trigonometric and logarithmic functions, calculation history, and seamless Light/Dark theme switching.

---

## Features

- **🧮 Scientific Functions**: Supports `sin`, `cos`, `tan`, `ln`, `sqrt`, exponents (`^`), and constants (`π`, `e`).
- **📜 Calculation History**: Keep track of your past calculations with an interactive modal bottom sheet.
- **🌗 Theme Switcher**: Toggle seamlessly between custom Light and Dark modes.
- **📱 Responsive UI**: Clean and intuitive keypad layout suitable for Mobile and Web platforms.
- **⚡ Real-time Evaluation**: Powered by robust expression parsing using the `math_expressions` package.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Make sure you have installed:
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Chrome Browser](https://www.google.com/chrome/) (for Web debugging) or an Android/iOS Emulator

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/scientific_calculator.git](https://github.com/YOUR_USERNAME/scientific_calculator.git)
   cd scientific_calculator

  ---

  ### Get dependencies:

  flutter pub get

  ### Run the application [On Chrome (Web)]

  flutter run -d chrome
